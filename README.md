# C Parser & AST Visualizer

Синтаксичний аналізатор мови програмування C з використанням Lex/YACC, включаючи семантичний аналіз, генерацію коду та візуалізацію AST.

## Використання

### Командний рядок:
```bash
# Аналіз файлу
./c_parser input.c

# Інтерактивний режим
make interactive

# Запуск тестів
make test
```

### Веб-інтерфейс:
```bash
# Відкриття візуалізатора
make web
# або відкрийте visualizer.html у браузері
```

## Підтримувані конструкції C

### Типи даних:
- `int`, `float`, `double`, `char`, `void`

### Оператори:
- Арифметичні: `+`, `-`, `*`, `/`, `%`
- Порівняння: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Логічні: `&&`, `||`, `!`
- Присвоєння: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- Інкремент/декремент: `++`, `--`

### Конструкції:
- Функції з параметрами
- Умовні оператори (`if`, `else`)
- Цикли (`for`, `while`)
- Блоки коду `{}`
- Оператор `return`
- Виклики функцій

## Вихідні файли

Після аналізу генеруються:
- `ast.json` - AST у форматі JSON для візуалізації
- `generated.c` - Згенерований код
- Консольний вивід AST у текстовому форматі

## Команди Makefile

```bash
make all          # Компіляція (за замовчуванням)
make test         # Запуск тестів
make interactive  # Інтерактивний режим
make web          # Відкриття веб-візуалізатора
make docs         # Генерація документації
make clean        # Очищення проміжних файлів
make distclean    # Повне очищення
make install-deps # Встановлення залежностей
make check-deps   # Перевірка залежностей
make package      # Створення архіву проекту
make help         # Довідка
```
