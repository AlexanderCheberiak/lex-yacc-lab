# C Parser & AST Visualizer

Синтаксичний аналізатор мови програмування C з використанням Lex/YACC, включаючи семантичний аналіз, генерацію коду та візуалізацію AST.

## Особливості

- ✅ Лексичний аналіз (Lex) для токенізації C коду
- ✅ Синтаксичний аналіз (YACC) з граматикою C
- ✅ Побудова AST (Abstract Syntax Tree)
- ✅ Семантичний аналіз та генерація коду
- ✅ Візуалізація AST з D3.js у веб-браузері
- ✅ Інтерактивний веб-інтерфейс
- ✅ Тестові приклади

## Підтримувані конструкції C

### Типи даних:
- `int`, `float`, `double`, `char`, `void`

### Оператори:
- Арифметичні: `+`, `-`, `*`, `/`, `%`
- Порівняння: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Логічні: `&&`, `||`, `!`
- Присвоєння: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- Інкремент/декремент: `++`, `--`

### Конструкції:
- Функції з параметрами
- Умовні оператори (`if`, `else`)
- Цикли (`for`, `while`)
- Блоки коду `{}`
- Оператор `return`
- Виклики функцій

## Приклади використання

### Простий приклад:
```c
int main() {
    int x = 5;
    int y = 10;
    int sum = x + y;
    return sum;
}
```

### Функції:
```c
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(3, 4);
    return result;
}
```

### Цикли:
```c
int main() {
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        sum = sum + i;
    }
    return sum;
}
```

## Технічні деталі

### Лексичний аналіз:
- Розпізнавання ключових слів C
- Токенізація операторів та розділювачів
- Обробка літералів (числа, рядки, символи)
- Ігнорування коментарів та пробілів

### Синтаксичний аналіз:
- LALR(1) граматика для C
- Побудова AST під час парсингу
- Обробка помилок з детальними повідомленнями

### AST:
- Ієрархічна структура вузлів
- Зберігання типів даних та значень
- Підтримка всіх конструкцій C

### Генерація коду:
- Відновлення C коду з AST
- Збереження структури та логіки

## Розробка

```bash
# Аналіз покриття коду
gcc -fprofile-arcs -ftest-coverage -o c_parser *.c
./c_parser test.c
gcov *.c
```
